Formula Cheatsheet & Quick Derivations

Quorum Consensus Math R + W > N
N = replicas, R = read quorum, W = write quorum.
Strict consistency: R + W > N && W > N/2
For PBFT fault tolerance: N >= 3f + 1
Guarantees overlap of read and write sets under network partitioning.
Vector Clock Updates V_i[j] Rule
Local event at P_i: V_i[i] = V_i[i] + 1
Message send: piggyback V_i
On receive m: V_i[k] = max(V_i[k], m.V[k]) for all k
Enables exact causal graph verification and detection of concurrent operations.
